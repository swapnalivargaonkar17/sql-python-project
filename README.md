# Healthcare Data Analysis using Python & SQL

## Project Overview

This project focuses on analyzing healthcare data using Python and SQL.

The project analyzes patients, doctors, appointments, billing, and diagnosis data to identify useful healthcare and business insights.

## Tools & Technologies

- Python
- Pandas
- NumPy
- MySQL
- SQL
- Jupyter Notebook
- Git & GitHub

## Dataset

The project contains five datasets:

- Patients
- Doctors
- Appointments
- Billing
- Diagnoses

### Dataset Size

| Dataset | Records |
|---|---:|
| Patients | 1,200 |
| Doctors | 50 |
| Appointments | 5,000 |
| Billing | 5,000 |
| Diagnoses | 5,000 |

## Python Analysis

Python was used for:

- Data loading
- Data cleaning
- Missing value analysis
- Duplicate value checking
- Data type validation
- Date conversion
- Exploratory Data Analysis
- KPI calculation
- Appointment analysis
- Revenue analysis
- Diagnosis analysis
- Patient spending analysis
- Doctor appointment analysis

## SQL Analysis

MySQL was used to perform:

- Overall healthcare KPI analysis
- Patient demographic analysis

- Appointment status analysis
- Treatment-wise revenue analysis
- Payment method analysis
- Diagnosis analysis
- Diagnosis severity analysis
- Doctor-wise revenue analysis
- Monthly appointment and revenue analysis
- Cancellation rate analysis

- Subquery analysis
- Window function and ranking analysis
